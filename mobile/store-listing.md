# App Store listing copy

Paste into App Store Connect. Character counts are Apple's limits, checked
against the text below rather than estimated.

- **Name** (30): `InternetDJ Radio`
- **Subtitle** (30): `Underground electronic music`

## Subtitle

Apple indexes the name and the subtitle together and weights them above
everything else, so the subtitle's job is to carry the highest-value words the
name does not already contain. "Radio" is in the name, so repeating it there
spends six characters on a term already indexed.

Recommended, because "electronic" is the single term most people will actually
type and "underground" is the one that separates this from a major-label
catalogue:

```
Underground electronic music
```
28 characters.

Alternatives, all inside the limit:

| Subtitle | Chars | Trades |
| --- | --- | --- |
| `Underground electronic music` | 28 | best search coverage |
| `Independent electronic music` | 28 | "independent" over "underground" |
| `Underground music, since 1997` | 29 | the distinctive hook, but loses "electronic" |
| `Electronic mixes, since 1997` | 28 | both, at the cost of "underground" |

The 1997 line is the most memorable thing here for a human reading the page, but
it earns nothing in search. It already opens the description and can go in the
promotional text, which is where a story belongs and where it can be changed
without a review.

## Category

- **Primary: Music.** Unambiguous, and where anyone browsing for this would look.
- **Secondary: Entertainment.** The conventional pairing for a listening app and
  a second chart to appear in.

Both must be accurate rather than chosen for a softer chart. Music is heavily
contested and this app will not chart on it early; the category is for browsing
and for how Apple understands the app, not a growth lever.

## Description (4000)

```
Press play. It keeps going.

InternetDJ Radio is an endless mix of independent electronic music, built from
what actually goes together. Every track is picked by tempo, musical key and
genre, so one record follows another the way it would in a set rather than the

It tells you why, too. Under every track is the reason it followed the last one:

NO ACCOUNT, NO SIGN-UP
```

## Notes

**App privacy.** The app has no account and collects nothing directly. It does
call the InternetDJ API, and plays are de-duplicated by IP on the server. Answer
the questionnaire against that rather than assuming "not collected" - a wrong
answer here is a rejection.

**Age rating.** Music is member-uploaded and unmoderated at upload time, so
expect to declare user-generated content.
